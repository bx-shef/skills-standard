## L1. shef.leadfinish — след установки (без решателя)
Модуль уже на стенде. Цель — измерить, а не чинить.
1. `bx.php status shef.leadfinish`, `bx.php footprint shef.leadfinish > L1-installed.txt`.
2. Если модуль установлен — `bx.php uninstall shef.leadfinish` → `footprint > L1-after-uninstall.txt`
   (это **не** `reset`: файлы остаются, только DoUninstall + принудительная зачистка с пометками «остаток — дефект»).
3. Снова поставить: `bx.php install shef.leadfinish` → `footprint > L1-reinstalled.txt`.
4. Сравнить три файла. В отчёт: что осталось после DoUninstall (каждая строка с пометкой «дефект» из шага 2),
   что появилось при повторной установке дважды (нет идемпотентности), строки `CORE-TOUCHED`.
Если модуль не был установлен — шаги 3 → 2 → 3, та же логика.
Ничего не править. Если `uninstall` роняет PHP — записать ошибку, модуль оставить как есть, L2 всё равно делать.
